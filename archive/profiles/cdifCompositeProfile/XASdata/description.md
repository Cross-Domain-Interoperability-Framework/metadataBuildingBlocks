## CDIF XAS metadata

Composite profile assembling building blocks for an extended CDIF schema.org implementation of the [Cross Domain Interoperability Framework](https://cross-domain-interoperability-framework.github.io/cdifbook/metadata/schemaorgimplementation.html#implementation-of-metadata-content-items) to document X-ray absorption spectroscopy (XAS) data. Composes cdifCore + cdifDiscovery + cdifDataDescription with the two XAS conformance tiers xasCore (mandatory) and xasOptional (optional). See README.md for details.
