Definition

Documentation ============= Original -------- Reference ......... cdi:ArchivePart CDIF ---- Definition .......... A component file within an archive distribution. Typed schema:MediaObject. May itself carry cdif:hasPhysicalMapping and the cdi: physical-dataset co-typing when the part is a tabular or structured data file.
