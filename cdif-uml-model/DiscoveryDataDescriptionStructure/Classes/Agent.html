Definition

Documentation ============= Original -------- Reference ......... cdi:Agent Definition .......... Definition ========== Something that bears some form of responsibility for an activity taking place, for the existence of an entity, or for another agent's activity. (See the W3C PROV-O ontology, https://www.w3.org/TR/prov-dm/#term-agent) CDIF ---- Definition .......... Abstract supertype for actors that can play roles on a dataset (creator, publisher, contributor, funder). Use Person or Organization as the concrete realisation.
