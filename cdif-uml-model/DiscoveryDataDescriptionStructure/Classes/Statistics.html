Definition

Documentation ============= Original -------- Reference ......... cdi:Statistics Definition .......... Definition ============ Statistics related to an instance variable within a data set. Examples ========== The percentage of females from a demographic data set. CDIF ---- Definition .......... A named bundle of one or more Statistic value objects for an instance variable, optionally weighted, optionally broken down by Category. Scope ..... A named bundle of statistic value objects for an instance variable: typeOfStatistic, scale, content / numeric value, etc. Optionally weighted (by an InstanceVariable) and applies to one or more InstanceVariables.
