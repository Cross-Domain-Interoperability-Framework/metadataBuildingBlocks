CdifConceptOrTermOrString

CDIFCore::Classes::CdifConceptOrTermOrString

Definition

Union shorthand for 'a plain string OR the CdifConceptOrTerm 3-way union (skos:Concept @id-ref | schema:DefinedTerm | inline cdif:Concept)'. In JSON instances the value MAY be: (a) a plain string label, (b) an @id-only object referencing a SKOS concept, (c) a schema:DefinedTerm node, or (d) an inline cdif:Concept.
