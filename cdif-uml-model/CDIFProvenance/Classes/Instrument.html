Instrument

CDIFProvenance::Classes::Instrument

Definition

Documentation ============= Original -------- Reference ......... schema:Thing Definition .......... The most generic type of item. CDIF ---- Definition .......... An instrument or tool used by a provenance activity. Typically a software package or piece of equipment; recorded inline under prov:used items via the schema:instrument sub-key. Carries identifier, label, optional version, and free-form descriptive properties.
