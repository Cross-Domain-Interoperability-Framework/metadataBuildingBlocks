Documentation ============= Original -------- Reference ......... cdi:StructuredDataSet Definition .......... Definition ========== Information describing the physical aspects of a data set using a binary or highly structured text-based encoding. Examples ======== NetCDF, HDF5, Parquet or XML data files, each with the means of referencing collections of data points associated to an instance variable via a logical expression. For instance, XPath can be used to navigate an XML data structure and locate the relevant data points. CDIF ---- Definition .......... DataDownload co-typed as cdi:StructuredDataSet: hierarchical / structured data set (XML, JSON, ...). Per-field mappings are LocatorMapping.
